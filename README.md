# todolist-server

CRUD логика тудулиста

## установка

```bash
git clone https://github.com/Granit-700/todolist-server.git
cd todolist-server
npm i
```

## Запуск

```bash
npm run dev
```

### Внимание!

Перед запуском создать `.env` файл в корне проекта со следующими переменными:

```
PORT=3000
DB_URI=your_mongodb_connection_string
```

## Стек

JavaScript, Node.js, Express, Mongoose
